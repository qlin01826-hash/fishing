# 战斗段 · 水下双层追猎（天地轨）设计规范

> 阶段：`BattleState` · 企鹅跃入水中追鱼  
> 参考：Arcaea Sky/地面双层、一点透视冲刺隧道  
> Wireframe：`design/battle-wireframe.html`（纵深 + 判定线俯冲）

---

## 0. 设计一句话

玩家在**固定判定站台**上操控**左翼企鹅 / 右翼企鹅**，在强烈透视的深海隧道里：  
- **底层**吃鼓点气泡（Tap/Hold）  
- **空中**追发光鱼群流线（Arc/Hold）  
所有音符从消隐点俯冲而来，在**下方判定线**与企鹅交汇 — 过山车过站，而非轨往上飘。

---

## 1. 核心玩法转译

### 1.1 透视与冲刺感

| 要素 | 规范 |
|------|------|
| 透视 | **一点透视**，消隐点居中偏上（`horizon ≈ 20%H`） |
| 纵深 | 拍点 `ab→0` 必落 **判定线** `judgeY ≈ 82%H`；远处小、近处大 |
| 镜头 | 轻微 pitch/bank lerp，**不跟拍抖动**；冲刺感来自轨+粒子迎面而来 |
| 画幅 | 横屏主战斗；左右 peripheral 用于鱼群 Arc 横摆 |

### 1.2 天地双层（谱面语义）

```text
                    ◎ 目标鱼（消隐点深处）
                         ╲
          ～～ 鱼群 Arc ～～～～  （天空层 · 旋律/人声）
                         ╱
    ─── 海底 4 车道 ─── 判定线 ───
         ○ ○ 气泡      🐧L   🐧R
         （地面层 · 鼓点/低音）
```

| 层 | 音轨来源 | 音符形态 | 输入 |
|----|----------|----------|------|
| **海底洋流（Ground）** | 鼓点、低音、底拍 | 上浮半透明**气泡** / 发光**珍珠**；Hold=拉长的气泡串 | **左手** 企鹅（或左半屏） |
| **鱼群航线（Sky）** | 主旋律、人声、长音 | **发光小鱼群**游过留下的流线轨迹=Arc；Hold=鱼群持续滑过 | **右手** 企鹅（或右半屏） |

- 取消「科技感硬发光管」；Sky 轨=**鱼群尾迹**（沙丁鱼带、水母伞缘、磷光点群）。
- Ground 轨=**沙砾洋流车道**（4 条透视车道线 + 暖沙光）。

### 1.3 双企鹅交互

| 手 | 角色 | 按住 Sky Arc 时 |
|----|------|-----------------|
| 左 | 左翼企鹅 | 负责 Ground 层 Tap/Hold；追底拍气泡 |
| 右 | 右翼企鹅 | 负责 Sky 层 Arc/Hold；**翻滚加速**紧随鱼群 |

Hold 视觉：右翼企鹅 3D 翻滚（bank + 俯仰），身周**尾流气泡**；左翼压入洋流车道，身后**沙砾拖尾**。

判定站台：两只企鹅 Y 固定于判定线，仅 **lx** 随输入横移（与当前 wireframe 一致，扩展为双实体）。

## 2. 手性与色彩语义（0.1s 可辨）

### 2.1 原则：**色相分工 + 亮度锁定 + 动势分工**

水下环境整体冷暗；**左右手不靠「左右位置」单独区分**（双眼需颜色+形状）。

| 语义 | 左手 Ground | 右手 Sky |
|------|-------------|----------|
| **主色相** | 暖琥珀 / 珊瑚橙 `#FF9E6C → #FFD4A8` | 冷青 / 磷光蓝 `#4EC8E8 → #A8F0FF` |
| **辅色** | 沙金颗粒、珍珠白核心 | 深海水母紫边 `#9A7AFF`（仅描边 15%） |
| **形状** | 圆/椭圆气泡、珍珠 | 细长鱼群带、菱形 Arc 锚点 |
| **动势** | **向上浮**（鼓点顶起） | **横向掠**（旋律滑行） |
| **触控区** | 左下 40% 宽（与 `LurePads` 左对称） | 右下 40% 宽 |

### 2.2 0.1s 防混乱规则

1. **禁止**左右使用同一饱和色；Ground 永暖、Sky 永冷。  
2. **音符主体**用纯色块，环境用去饱和蓝绿；对比度比 ≥ 3:1（音符 vs 背景）。  
3. **同时出现**时：Ground 在**判定线下方略低 8px**，Sky 在**判定线上方 12–40px**（纵深投影），永不重叠同一 Y。  
4. **紧急提示**：仅错手时闪**半屏极淡**暖/冷 tint 50ms，非常驻。  
5. **色盲**：Ground 加**圆形**外轮廓；Sky 加**菱形**锚点（形状先于颜色）。

### 2.3 企鹅本体

| | 左翼 | 右翼 |
|--|------|------|
| 胸甲/翼尖 | 暖橙小斑 | 冷青小斑 |
| Hold 态 | 脚蹼蹬沙 | 身体翻滚 + 鱼群环绕 |
| Miss | 短促「气泡浑浊」 | 鱼群散开一帧 |

## 3. 视觉层级与特效分层

### 3.1 渲染顺序（后→前）

```text
L0  环境远场     礁石剪影、远鲸、体积雾（低对比）
L1  丁达尔       顶部 god ray，随 shallow 强弱
L2  透视地面     4 车道沙砾线 → 消隐点
L3  地面影       鱼群/气泡在沙地上的投影（暗 20%）
L4  Sky 鱼群轨   半透明鱼群 mesh + 尾迹
L5  Ground 音符  气泡/珍珠（高亮核+柔边）
L6  角色         双企鹅 + 尾流
L7  判定线       粉紫细线 + 车道圆点（最高对比）
L8  UI HUD       Combo、意志、张力（描边+半透明底）
L9  反馈粒子     Pure 时的短生命周期水花（见 §4）
```

### 3.2 环境与读谱对比

| 层 | 饱和度 | 动态 | 备注 |
|----|--------|------|------|
| 海水背景 | 25–35% | 慢速微粒 | 手绘噪点+渐变，禁止高频闪 |
| 礁石 | 15% 剪影 | 静态视差 | 不与车道同 lx 范围 |
| 车道线 | 50% 暖沙 | 随 scroll 迎面 | 线宽近粗远细 |
| 音符 | **85–100%** | 拍点缩放 1.0→1.15 | 内核白点固定 2px |
| 判定线 | 90% 粉紫 `#D878B8` | 拍头 pulse 仅线宽+2px | 不震屏 |

### 3.3 UI 安全区（横屏 844×390）

```text
┌─────────────────────────────────────────────┐
│ 张力条 · 分数 · Combo（L8，顶 12%）          │
│                                             │
│          [ 透视隧道 + 双层轨 ]               │
│                                             │
│  ═══════════ 判定线 judgeY 82% ═══════════  │
│  🐧L          lane dots          🐧R       │
│  [左触区]                      [右触区]     │
└─────────────────────────────────────────────┘
```

- Combo 数字：顶中，**描边 2px + 阴影**，字体 tabular；Pure 时数字微跳，不换色。  
- 意志/张力：保持现有条，但战斗时 **opacity 0.85**，避免挡隧道中心。

### 3.4 手绘质感实现提示（Pixi）

- 背景：多层 `Graphics` + 低 alpha 噪点 tile，不用纯矢量平涂。  
- 鱼群轨：`MeshRibbon` + 正弦偏移顶点，贴图用 2–3 帧鱼剪影循环。  
- 气泡：径向渐变圆 + 1px 高光点；Hold 用串联 3 个气泡而非实心条。  
- 水体折射：判定线以下 **轻微 wobble UV**（幅度 ≤2px），以上保持稳定读谱。

## 4. 正向反馈（灵动、不污染）

### 4.1 Pure / Perfect 原则

- **短**：粒子寿命 0.25–0.45s  
- **少**：单次 ≤12 颗粒  
- **局部**：只在判定交汇点 ±60px  
- **无**全屏闪白、无大面积 bloom 叠加

### 4.2 Ground Pure（吃气泡）

| 效果 | 描述 |
|------|------|
| 气泡破裂 | 4–6 个小泡向外弹，暖色，重力向上飘 |
| 珍珠闪 | 内核一次白闪后消失（1 帧） |
| 沙砾涟漪 | 判定线处 1 圈扩散步长 30px，alpha 0.3→0 |
| 左翼企鹅 | 胸甲暖斑亮 0.2s；脚蹼蹬沙 3 粒沙金 |

### 4.3 Sky Pure（追鱼群）

| 效果 | 描述 |
|------|------|
| 鱼群汇入 | 2–3 条小鱼折向企鹅，0.3s 后 dissolve |
| 磷光尾迹 | 冷青细线拖尾 0.2s，沿 Arc 切线 |
| 右翼翻滚 | 额外半圈 roll（仅视觉，0.15s） |
| 水纹 | 横向一道细波纹沿判定线扩散 |

### 4.4 Good / Miss 区分

| 判定 | 反馈 |
|------|------|
| Good | 上述效果 **减半** 颗粒；音符 tint 保持 |
| Miss | 气泡变浊灰 0.3s；鱼群「惊散」1 帧位移，**无**红屏 |
| 连击断 | Combo 数字沉底淡出，不震屏 |

### 4.5 Frenzy 与战斗高潮

- 鱼群密度+1 档，**不改**左右色相。  
- 背景 god ray 略强（+10%），禁止加第二套粒子系统。  
- 双企鹅之间偶发「击掌水泡」仅 Frenzy 每 4 拍一次。

## 6. 与现有拔河逻辑的关系

- **短期**：保留 `BattleState` 意志/张力数学；视觉改为双层追猎，底拍 Tap 映射 Ground 层。  
- **中期**：Sky Hold 对应「追鱼 Arc」；Perfect 同时要求 **手正确 + 拍正确 + lx 偏差 < 阈值**。  
- **长期**：PullPanel 退役为战斗输入，改为左右触区 + 判定线瞄准（与 wireframe 点击横移一致）。
